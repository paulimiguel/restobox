# Extensión Chrome de RestoBox

La extensión abre el importador de RestoBox con la URL de la página activa. También muestra un botón flotante cuando detecta una página relacionada con un restaurante o lugar gastronómico.

En cualquier página web, presioná **Shift+R** para abrir la extensión. El atajo se desactiva mientras escribís en un campo de texto.

Para instalarla, descomprimí `restobox-extension.zip`, abrí `chrome://extensions/`, activá el modo desarrollador y elegí **Cargar extensión sin empaquetar**.
